我之前一直说"AI bot / 考官系统 / Agent 应用 / 智能体"——这些词让你以为我们搭了一个会跟学生对话的智能体。飞书多维表格不是 Agent，我们昨天搭的也不是聊天系统。

飞书多维表格 到底是什么

本质 数据库 + 智能电子表格（类 Airtable / Notion 数据库）
能做 建表、加列、写数据、做不同视图（表格 / 看板 / 日历 / 表单）

不能做 跟学生对话 · 当聊天机器人 · 作为面向用户的产品

  • W1 一周可能完不成
