💡 一句话总结技术差异
Speak 是 "speech-to-speech"（语音直传语音），技术上叫 OpenAI Realtime API，2024 年 10 月才推出。Speak 是第一批切到这个 API 的产品，OpenAI 官方把它列为 case study。Duolingo Max 还没切，所以 Lily 反应慢、感觉像呆呆的。

④ "自研 ASR" 是什么 · 用"耳朵"来类比

ASR = Automatic Speech Recognition（自动语音识别）= 让 AI 把你说的话变成文字。可以理解为 AI 的"耳朵"。

Speak 没有用 OpenAI 现成的 ASR（叫 Whisper），而是自己训了一对耳朵，用自家用户的录音 fine-tune。

WER = Word Error Rate（识别错误率），越低越好。Speak 在它技术博客里写自家 ASR 比 Apple / Azure 强 — 这是它自报数据，没有第三方验证，但说明它在 STT 这一层是认真投入的。

💡 这对你 Flashcard 升级的启发
如果你 Flashcard 加语音识别，OpenAI Whisper API 是公平起点（直接调，省事），但 Speak 证明自己 fine-tune 一对"雅思耳朵"（用雅思考生录音训）能甩开第三方 40-60% 的 WER。这是 Speak 没做的事——它 ASR 是通用的，没有专门为雅思口语优化。

⑤ "间隔重复"是什么 · 你 Flashcard 工具的核心机制

Spaced Repetition = 间隔重复。简单说：越熟的词，复习间隔越长；越生的词，复习间隔越短。这是 Flashcard / Anki / Quizlet 等记忆类工具的核心算法，基于德国心理学家 Ebbinghaus 的遗忘曲线。

💡 这是 Speak 没做的事 — 你的护城河
Speak 的 Phrasebook 只是单向存档（你存进去就完了），不会主动把这些词重新塞进对话里让你练。Languatalk 评测原话："Phrasebook is a one-way storage." 你的 Flashcard 工具天然就是 spaced repetition 设计的——这是 $1B 估值的 Speak 都没做的功能，是你的明确产品差异化空间。

⑦ 看完后回去看 P2 主文 · 关键术语小词典

Speak / speak.com
OpenAI 投资的 AI 口语学习 App，2016 创立，2024-12 估值 $1B（独角兽）。主战场韩国 / 日本，韩国 App Store 教育类 #1。
Connor Zwick
Speak 创始人 + CEO，Thiel Fellowship "20 Under 20" 出身。
Live Roleplay
Speak 的核心 AI 功能，2024-10 上线。用 OpenAI Realtime API + GPT-4o 做端到端语音对话。
Realtime API
OpenAI 2024-10 推出的接口，让 AI 直接"听到说"不用中转文字。P1 推测 Duolingo Max 没切的就是这个。Speak 是第一批切的产品。
Speech-to-Speech / 端到端
语音输入直接生成语音输出，不经过文字中转。延迟可低至 200ms（接近真人对话）。
STT → LLM → TTS
三段式语音管道：Speech-to-Text → 大模型 → Text-to-Speech。延迟 1-2 秒，丢失语调情感。Duolingo Max Video Call 用的就是这个（推测）。
ASR / Automatic Speech Recognition
自动语音识别，把你说的话变文字。可以理解为 AI 的"耳朵"。Speak 自己训了一对（Conformer-CTC 架构）。
Conformer-CTC
一种 ASR 模型架构，自注意力 + 卷积结合。Speak 用 Nvidia NeMo framework 自己训的。
WER / Word Error Rate
识别错误率。Speak 自报 WER 比 Apple Speech / Azure Speech 好 — 但没有第三方验证。
Spaced Repetition / 间隔重复
记忆科学的核心算法，越熟越间隔越长。Speak 没做这个，你 Flashcard 工具天然就有，这是你的护城河。
ARR / Annual Recurring Revenue
年度经常性收入（订阅类业务的核心指标）。Speak 一年从 $50M → $100M+。
Speak for Business
Speak 的 B 端产品，2024 启动，2 年做到 500+ 企业（KPMG / Hyundai），员工 adoption 85%。P2 的核心战略洞察 — B 端市场已被验证。
